## QR Code Generator using Python

This project is a simple **QR Code Generator** built using **Python**.  
It allows users to generate QR codes for text, URLs, or any input data quickly and efficiently.

---

## 🔹 Features
- Generates QR codes for text and URLs
- Fast and easy-to-use
- Saves QR code as an image file
- Lightweight Python application

---

## 🛠 Technologies Used
- Python
- qrcode library
- Pillow (PIL)
